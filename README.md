# Product Manager Application

A Java Swing desktop application for managing product inventory with MySQL database integration.

## About

This is a study project created for learning purposes, demonstrating:
- Java Swing GUI development
- Database connectivity and CRUD operations
- Custom annotations and reflection
- MVC-like architecture pattern

## Features

- Product listing with pagination and filtering
- Add, edit, and delete products
- Image support for product visualization
- Custom table model with sorting capabilities
- MySQL database integration

## Technologies

- Java
- Swing (GUI)
- MySQL
- Lombok
- JDBC

## Structure

```
src/app/
├── App.java              # Main application entry point
├── annotation/           # Custom annotations
├── entity/              # Data models
├── manager/             # Database operations
├── ui/                  # User interface forms
└── util/                # Utility classes
```

## Note

This is an educational project developed for learning Java desktop application development.
